# ДЗ 3: прогноз покупок клиента за 30 дней

Стартовые бейзлайны для [HW3 ML MIPT autumn 2026](https://www.kaggle.com/competitions/hw-3-ml-mipt-autumn-2026). Цель — `spend_30d`, метрика — RMSLE.

## Бейзлайны

| Имя | Подход | Фиксированные настройки |
|---|---|---|
| `logmean` | Среднее `log1p` сумм шести предыдущих 30-дневных окон, включая нулевые | Без обучения |
| `ridge` | Линейная регрессия с L2 на `log1p(spend_30d)` | `alpha=10` |
| `forest` | Случайный лес на `log1p(spend_30d)` | 200 деревьев, глубина 12, минимум 20 строк в листе |
| `mlp` | Полносвязная сеть на `log1p(spend_30d)` | Скрытые слои 128/64, ReLU, Adam, 60 эпох |

Модели выбраны вручную. Настройки находятся в `configs/baselines.json`; автоматического поиска алгоритмов, архитектур или гиперпараметров нет. Бустинги, AutoML и внешние данные не используются.

## Данные

Скачайте четыре исходных CSV с вкладки Data соревнования и положите их в `data/raw/`:

```text
data/raw/transactions.csv
data/raw/train.csv
data/raw/test.csv
data/raw/sample_submission.csv
```

Данные, признаки отдельных клиентов, веса и файлы предсказаний исключены из Git. Репозиторий содержит код и агрегированные результаты.

Очистка удаляет точные повторы строк, операции без известного клиента, отмены с префиксом `R`, неположительные количества/цены, `SVC00`–`SVC13` и позиции с префиксом `GFT`. Товарные покупки агрегируются по клиенту и дате. При запуске восстанавливаются **все известные train-ответы**; расхождение больше 0,011 УЕ останавливает расчёт.

## Установка и запуск на CPU

Рекомендуется Python 3.12. Команды выполняются из корня репозитория.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[neural]'
python -m unittest discover -s tests -v
python -m spend_baselines validate --models logmean ridge forest mlp --device cpu --threads 2
```

Без установки PyTorch доступны первые три модели:

```bash
python -m pip install -e .
python -m spend_baselines validate --models logmean ridge forest
```

Метрики сохраняются в `outputs/baselines/scores.csv`, конфигурация, версии и SHA256 исходников — в `run_manifest.json`. Также сохраняются локальные прогнозы и кривая обучения MLP. Параметр `--epochs 2` позволяет явно запросить короткий пробный запуск; он записывается в манифест.

## Запуск MLP на V100

Для Linux-сервера с V100 предусмотрен явный выбор CUDA. В отдельном окружении Python 3.12:

```bash
python -m pip install -e .
python -m pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu121
python -m spend_baselines validate --models mlp --device cuda --threads 2 --out-dir outputs/mlp-v100
```

Команда установки соответствует [официальной инструкции PyTorch 2.5.1](https://pytorch.org/get-started/previous-versions/#v251). GPU-запуск должен выполняться на машине с доступным CUDA-устройством. Если CUDA недоступна, команда завершится с явной ошибкой.

## Временная проверка

- Проверочные даты: **1 сентября и 1 октября 2018**.
- В обучение каждой проверки попадают только строки с `target_end <= validation_date`.
- Каждый признак использует операции **строго до `as_of_date` своего объекта**.
- Заполнение пропусков и масштабирование обучаются только на обучающей части.
- ID клиента служит связыванию таблиц и не является числовым признаком.
- MLP обучается фиксированное число эпох, без подбора по внешней проверочной выборке.
- Локальные RMSLE нельзя напрямую сравнивать с public leaderboard на другом наборе объектов.

Основные признаки: давность покупки, длина истории, число покупательских дней и суммы за 30/60/90/180 дней, последняя/средняя/медианная сумма, месяц. С помощью `--features extended` можно вручную проверить добавку ритма, дня недели, часов и вариативности сумм. Это отдельная проверяемая гипотеза.

## Локальный файл для Kaggle

После выбора модели по проверке:

```bash
python -m spend_baselines submit --model ridge --out-dir outputs/submission
```

Будет создан CSV с колонками `Id,spend_30d`, порядком строк из `sample_submission.csv` и конечными неотрицательными суммами в исходных УЕ. Обратное преобразование `expm1` выполняется в коде. Команда **не отправляет** файл в Kaggle.
