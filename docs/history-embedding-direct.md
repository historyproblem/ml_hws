# Обучаемый эмбеддинг истории + MLP: отдельная поздняя попытка

Пользователь прямо попросил позднюю отправку модели сэмбеддингом иMLP,
уточнил, что нужен эмбеддинг истории. Подготовлен один новый нейронный
кандидат с прямой регрессией. Предыдущие ограничения на бустинг, внешние
данные, трансформеры и AutoML сохранены. Архивные Joint/mean3 экспортёры
остаются выключенными.

## Где строится вектор

1. `spend_embeddings.data.build_bags` берёт положительные покупки строго
   за[t−180,t), одно событие товара за покупательский день.
2. Вес события2**(−age/90). Сохраняютсяtop128товаров по накопленному весу,
   веса нормируются к сумме1. Это входной взвешенныйmulti-hotвекторq.
3. Словарь fit только на прошлых обучающих историях: товар встречался
   минимум у3разных клиентов. Чужие/OOVтовары отображаются в нулевой вектор.
4. `spend_embeddings.direct.make_network`, `Network.forward`: обучаемая
   матрицаE даёт **h=Eᵀq**, размер32. PyTorchEmbeddingBag эффективно
   считает эту обычную линейную проекцию разреженного входа.
5. `[15RFM,h] → Linear128/ReLU → Linear64/ReLU → Linear1`.
   E иMLP обучаются совместно поMSE(log1p target), Adam. В прогнозе
   z ограничивается снизу0, затемexpm1.

Это именно совместно обучаемое нейронное представление. SVD-опыт хранится
отдельно. Один seed42, исходные50852объектаD0, без усреднения прогнозов,
таргет-истории илиcustomer_idlookup. Innerсловарь/модель иouterсловарь/модель
строятся отдельно сtarget_end<=cutoff. Число эпох выбирается на предыдущем
доступном месяце; сеть затем обучается заново. Новый широкийHPO не запускался.

Связь с материалами курса: линейные слои/ReLU/Adam — семинар3, обучаемые
представления — семинар7, одноцелеваярегрессия/MSE — семинар8. Это
исследовательская композиция этих блоков; готовый идентичный рецепт
weighteditempooling в семинарах не проверен, формальное разрешение
организаторов именно на такую композицию не утверждается. Ранее она
консервативно исключалась из минимального пресета. Здесь пользователь
явно попросил попробовать обучаемую историю, и реализован отдельный
scalar-output вариант без архивной двухчастной функции потерь.
