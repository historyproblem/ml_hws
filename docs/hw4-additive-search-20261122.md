# Additive/GAM: последовательный внутренний отбор

План записан до новых результатов 22 ноября в 12:58:25 UTC:
`hw4-additive-search-plan-20261122.json`,
SHA `9175fe329393c85434d01a9b4d2cbc6ad40778aeea7d152213cf9a4172db31ef`.
Это исследование на прежних development-кварталах, не новый нетронутый holdout.

Ровно 24 рецепта: шесть представлений × L2 `C = .01, .1, 1, 10`:

1. Исходный compact GAM: 94 поля после исключения года и cutoff-gap.
2. То же compact-представление со сплайнами всех 90 численных полей.
3. Вся собственная история из исходных 274 полей без peer-context.
4. Полный набор 346 полей.
5. Исходный GAM с двумя one-hot взаимодействиями: риск × район и риск × сезон.
6. Исходный GAM с весами давности, half-life четыре квартала, средний вес один.

Во всех вариантах абсолютные год и cutoff-gap исключены, сезон — категория.
Сплайны степени 2 используют только fit-квантили `0/.25/.5/.75/1`, постоянные
хвосты и не дублируют исходный столбец. Медианы, границы, стандартизация и OHE
оцениваются только на fit. Неполные/константные поля имеют объявленные fallback;
missing flags сохраняются. В широких вариантах неотрицательные counts/totals и
возрасты логарифмируются; signed change не логарифмируется. Полная L2,
`lbfgs`, `tol=1e-7`, `max_iter=5000`, без class weights. CPU ограничен двумя
потоками. Неконвергенция явно записывается как invalid, а не скрывается.

Для outer 2023Q3/Q4/2024Q1 сравниваются 24 рецепта только на предыдущем
inner-квартале 2023Q2/Q3/Q4. Побеждает наибольший inner AP; tie — меньший C,
затем фиксированный порядок сложности. Только выбранный таким образом
алгоритм и фиксированный исходный GAM/C=.1 получают внешние прогнозы.
Нельзя выбирать лучший из 24 по внешним AP. Совпадающие train/recipe jobs
переиспользуются: более ранний outer checkpoint может стать следующим inner.
Решение о рецепте записывается до получения соответствующего outer-прогноза.

Предварительно заданы raw и смесь вероятностей 75% context04 + 25% algorithm.
Допуск требует положительного среднего эффекта к context, неотрицательного
эффекта в ≥2 кварталах, worst-quarter ≥−.005; дополнительно — положительного
среднего эффекта к соответствующему фиксированному GAM и ≥2 неотрицательных
кварталов. Парные site-bootstrap интервалы номинальные, без поправки за отбор,
и не являются дополнительным gate. Ни один квартал не исключается по AP.

После допуска финальный рецепт определяется большинством трёх inner-побед:
tie — средний inner AP трёх численно завершённых jobs, затем меньше C и
сложность. При отсутствии допуска full-fit не выполняется. Если финальный
рецепт буквально исходный GAM/C=.1, разрешено только проверенное повторное
использование прежнего full-forecast с отметкой о дубликате, не новый результат.
Иначе выполняется один полный fit на всех 21 017 train-строках. Новых метрик
2024Q2/Q3 и автоматических Kaggle-загрузок нет.

```bash
python scripts/run_hw4_additive_search.py \
  --raw data --out analysis/additive-search \
  --feature-cache analysis/final-features/features.joblib \
  --baseline-cv /path/to/verified/baseline_oof.csv \
  --context-test /path/to/submission_04_context_cb.csv \
  --fixed-core /path/to/previous/additive \
  --bootstrap 2000 --resume
```

Raw/cache/builder/anchor/source/package SHA и заранее записанный план включены
в freeze. Jobs публикуются атомарно; модели проверяются reload EXACT. Resume
проверяет исходники, параметры, решения и байты артефактов. Новые исходники не
меняют старые frozen runners и `additive_logit.py`.

Синтетические проверки: исходная core design matrix EXACT совпала с исходным
трансформером; проверены train-only bounds/unknown categories/recency, 24-рецептный
последовательный pipeline, явный all-invalid stop, resume без fit и CSV-интерфейс.
Принудительный gate в QA используется только для проверки экспорта и не
является оценкой качества.

## Реальный результат

75 уникальных попыток job: 73 checkpoint завершились и были независимо
переиграны EXACT, две широкие C10-конфигурации явно записаны как численная
неконвергенция. Ни один квартал не исключён. Все три заново посчитанных
контроля A/C=.1 попредиктно EXACT совпали с прежними GAM OOF, max difference=0.
