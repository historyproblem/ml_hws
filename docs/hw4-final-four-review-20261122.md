# Независимая проверка финальных моделей HW4

22 ноября 2026. Критических ошибок в подготовке признаков, временных разбиениях, расчёте AP и составе трёх выпущенных CSV не обнаружено. Самое содержательное новое сравнение — регуляризованная логистическая модель с четырьмя сплайнами. В смеси с лучшим Public CatBoost она улучшила AP во всех трёх старых кварталах. На Public и Private эти новые файлы ещё не оценены по материалам проверки.

## Проверенные сравнения

В таблице разницы посчитаны относительно трёхseed context CatBoost 04. Его средний AP на старых 2023Q3, 2023Q4 и 2024Q1 — 0.267506. Все смеси состоят из 75% вероятности 04 и 25% вероятности указанной модели.

| Кандидат | Средний AP | Δ к 04 | Неотрицательных кварталов | Номинальный парный 95% интервал Δ |
|---|---:|---:|---:|---:|
| Аддитивная модель в смеси | 0.270840 | +0.003334 | 3/3 | [−0.000069, +0.006385] |
| Аддитивная модель отдельно | 0.271208 | +0.003701 | 2/3 | [−0.007848, +0.014940] |
| CatBoost d6 в смеси, остановка по внутреннему AP | 0.267940 | +0.000434 | 2/3 | [−0.001611, +0.002334] |
| XGBoost d4 в смеси | 0.267577 | +0.000071 | 2/3 | [−0.002043, +0.002078] |
| Десять seed исходного context CatBoost | 0.266499 | −0.001008 | 0/3 | [−0.003753, +0.001852] |

Для аддитивной смеси отдельные Δ равны +0.002137, +0.001975, +0.005890. Для отдельной модели они равны +0.004584, −0.004212, +0.010731. Смесь предпочтительна как первый кандидат по согласованности кварталов. У отдельной модели выше средний AP и больше разброс. Для двух смесей бустингов наблюдаемые преимущества малы относительно их неопределённости. Ни одно из этих сравнений не даёт оценку вероятности преодолеть ориентир Public 0.35212.

Обе аддитивные формулы были зафиксированы и оценены до выбора лучшего варианта семейства. Исходное правило раннера выпустило только отдельную модель с наибольшим средним AP. Выдача второй аддитивной смеси как четвёртого файла требует явного решения о составе финального портфеля. Она воспроизводится из того же полного fit и 04 без нового обучения или выбора веса. Это два проверенных прогноза одного семейства. У бустингов экспортируется по одному прошедшему варианту. Ансамбль из десяти seed не прошёл критерий допуска, полный fit для них не запускался.

## Проверка кода и артефактов

* **Входы.** Из официальных CSV повторно построены все три матрицы после удаления столбца target из строк запроса. Для всех 23 263 строк значения, имена признаков, категории и порядок совпали с сохранённым кешем: 346 базовых, 353 с переходами, 358 с сезонными статистиками. Та же проверка охватывает порядок строк между train и test.
* **История.** Базовый запрос использует свой snapshot и строгую границу history_before. Пары routine формируются из событий до отсечения, затем исключаются пары с неизвестным исходом. При расчёте условных частот и поправок на коды вычитается собственная площадка. Сезонный блок дополнительно проверяет завершение исторического квартала и исключает неоднозначные недельные ячейки на его границах. Неполнота записей в источнике остаётся возможной. [Переходы](../src/hw4_inspections/transition_features.py) · [Сезонный контекст](../src/hw4_inspections/seasonal_context.py)
* **Разбиение и метрика.** Внешний прогноз квартала строится на более ранних официальных обучающих кварталах. В главном поиске число деревьев выбирается по Logloss на предыдущем внутреннем квартале. В дополнительном опыте четыре заранее указанных значения сравниваются по сохранённому sklearn AP того же внутреннего квартала. Для D6 получены 200/100/200 деревьев, средний фолд с 100 деревьями переиспользован и воспроизведён. Внешний AP считается отдельно на каждом квартале, затем берётся равновесное среднее. Интервалы используют общие для моделей веса bootstrap по site_id. Поздние официальные обучающие кварталы входят в полный refit, их метрики в этих опытах не рассчитываются. [Основной раннер](../scripts/run_hw4_final_research.py) · [Выбор по внутреннему AP](../scripts/run_hw4_inner_ap_followup.py) · [Определение AP](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.average_precision_score.html)
* **Сплайны и регуляризация.** Из compact96 исключены год и разрыв между началом квартала и cutoff. Осталось 94 входа. Четыре показателя нагрузки получили квадратичные B-сплайны по квантилям fit с постоянными хвостами. Выбор узлов, ограничений диапазона, медиан, масштаба и категорий обучается только на fit-строках соответствующего периода. Для полного fit получено 243 столбца: 106 непрерывных компонент, 90 индикаторов отсутствия и 47 индикаторов категорий. Все коэффициенты признаков регуляризованы L2 при C=0.1, свободный член не штрафуется. Монотонность и отдельный штраф за кривизну не задавались. В оригинальном Chicago ridge-логите штрафовали только коэффициенты инспекторов. В Boston участник третьего места включал L2-логит в ансамбль четырёх методов. HW4 использует собственную спецификацию и свою цель. [Модель HW4](../src/hw4_inspections/additive_logit.py) · [Исходный код Chicago](https://github.com/Chicago/food-inspections-evaluation/blob/master/CODE/30a_glmnet_model.R#L89-L103) · [Решение Boston](https://github.com/drivendataorg/keeping-it-fresh/tree/main/3rd-place)
* **Файлы и объём вычислений.** Подписи freeze, зарегистрированные текущие исходники и выходные SHA проверены для пяти запусков четырёх раннеров. После привязки по row_id три CSV, выпущенные модельными раннерами, восстанавливаются побитно из полных прогнозов: отдельный логит, смеси D6 и XGB d4. В каждом 2246 строк. В начальном поиске 45 сохранённых внешних и полных моделей плюс 24 внутренних fit — 69. Дополнительные запуски дали 11 новых fit для D6, 3 для XGB с дополнительной регуляризацией, 4 для логита и 21 для ансамбля seed. Всего 108 новых обучений. Во время этой проверки выполнены только чтение, пересборка признаков и сверка массивов. [Аддитивный раннер](../scripts/run_hw4_additive.py) · [Ансамбль seed](../scripts/run_hw4_context_bag10.py)

Три старых квартала использовались при выборе моделей уже неоднократно. Bootstrap описывает изменчивость сравнения внутри этих данных и не исправляет смещение от отбора вариантов. Ранее открытые 2024Q2/Q3 проверяли конкретно тройную смесь 02 против двойной 01. Эти результаты не подтверждают новые модели независимо. Исходный Public 04 равен 0.34646. Для новой четвёрки до появления фактических scores правомерно говорить о готовых кандидатах и силе локальных свидетельств.
