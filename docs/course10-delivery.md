# Финальный ноутбук и код для фиксации решения

Во время V100-подбора `run_course10_fast_tuning.sh` подготовлен упаковщик
самодостаточного решения. Он не меняет и не перезапускает GPU-поиск.

После завершения вычислений:

```bash
git pull --ff-only
python scripts/package_course10_solution.py
```

Будут созданы:

* `outputs/course10-delivery/course10_solution_fallback.zip` — запасной обычный MLP;
* `outputs/course10-delivery/course10_solution_selected.zip` — выбранный ранней валидацией кандидат, если полный refit готов.

В каждом ZIP: **solution.ipynb**, фактический submission.csv, параметры,
картa источников семинаров, таблицы качества, зависимости и необязательный
малый точный RFM-cache. Веса тяжёлых моделей и исходные транзакции не включены.
Для воспроизведения положите четыре официальных CSV в data/raw внутри
распакованного каталога. Код полностью записан в ячейках ноутбука:
репозиторий импортировать не требуется. Сам ipynb можно скачать отдельно
из соответствующей папки; без дополнительного cache он пересчитает признаки
из сырой истории. Если используется cache изZIP, он независимо сверяется
с расчётом по transactions.csv.

Ноутбук содержит только обычный одноцелевой MLP/MSE, Ridge и RandomForest.
Выполняется ровно выбранная модель, seed42. Генератор специализирует наш
generic trainer до обычного MLP: ветки probability/hurdle/RNN/embeddings
в код ноутбука не переносятся. Тестом подтверждено побитное совпадение
предсказаний специализированного и исходного direct-trainer на одинаковых
данных/параметрах. GPU/CPU и версии библиотек могут менять траекторию SGD;
для точного воспроизведения предпочтительны прежние версии иV100.

Упаковщик проверяет полный refit без smoke, один predictor, seed42,
SHA артефактов и полный CSV в порядке sample. Smoke нельзя выдать за финал.
При незавершённом поиске готовится только fallback; так сохраняется
допустимое решение для фиксации до дедлайна.

**Нужен один окончательно выбранный вариант.** Ранний победитель подбора
может не подтвердиться на поздних датах: перед загрузкой выбранного CSV
смотрим confirmation_scores.csv/архив результатов. Не отправляйте оба ZIP
или все CSV как будто это одна модель. Пользовательский лимит4попытки
Kaggle упаковкой не расходуется.

Для одной конкретной версии:

```bash
python scripts/package_course10_solution.py --candidate fallback
python scripts/package_course10_solution.py --candidate selected
```

Роль ИИ описана в ноутбуке. Для защиты нужно понимать очистку, 15признаков,
почему MSE(log1p) соответствует RMSLE, временной purge, подбор эпох/HP и
выбранный единственный регрессор. Ноутбук не включает автоматически
заявленную оценку Kaggle: ранее сообщённая2.77883 относилась к другой,
архивной Joint+history версии.
