## TabM: следующий полноценный GPU-опыт

Используются официальные tabm0.0.3 и rtdl-num-embeddings0.0.12,без внешних весов.
Две модели: k1 и k32 на одинаковых полных 346 признаках,PLE16/embedding8,
3 блока width256/dropout.1. AdamW lr.002/wd.0003,clip1,FP32,безAMP.
При обучении усредняются отдельные member-BCE,при прогнозе — вероятности.
Категории,imputation/scaling и числовые bins fit только на раннем train.
Это самостоятельный контролируемый ансамблевый метод,не ещё один ResNet.
[Официальный пакет](https://github.com/yandex-research/tabm).

Прежние 3 dev,seed42,innermax60/patience10/batch256;AP ансамбля выбирает эпоху
на предыдущем квартале. Затем новый outer-fit с выбранным числом эпох.
Итоговый k32 получает медиану трёх выбранных inner-чисел и refit на всех 21017.
Новых Q2/Q3-оценок/подбора не будет. k1 — контроль,не автоматически новый
submission. По возвращении проверяются standalone k32 и единственная
заранее заданная смесь 75% нынешнего context rank +25% TabM rank,каждая
отдельно по тому же допуску. Слабый standalone не блокирует полезный blend.

официальных CSV вdata/. Точный currentcontext уже хранится на Маке;его смесь
