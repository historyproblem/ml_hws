## Сезонный уровень рынка

Обучающие ответы центрируются по дате; входы — по доступной прогнозной популяции той же даты, без ответов. Обычная регрессия оценивает отклонение клиента. К нему прибавляется средний log1p-ответ прошлогодней активной180-дневной популяции за аналогичное30-дневное окно плюс0.5 среднего годового изменения последних трёх завершённых сопоставимых окон.0.5 задано заранее и после Kaggle не менялось. При отсутствии покрытия используются только завершённые прошлые окна.

Все17 средних старых популяций, восстановленные из внутренних транзакций, совпали с официальными целями. Каждый использованный исторический target_end<=текущего cutoff. Текущая/будущая метка не является входом. Центрирование обучающего ответа — преобразование отклика после временного purge, а не target encoding признака.

Прогноз MLP требует целую известную популяцию одного cutoff: отклонения центрируются по ней. Это одно нейросетевое предсказание с фиксированным прошлым сезонным уровнем; усреднения нескольких обученных моделей нет. Для ноября2018 сезонный уровень2.322023.

Фактический исход Kaggle: Public улучшился на0.00522, Private ухудшился на0.00564. Нового лучшего Private на этом этапе нет. Малая локальная разница с CI, включающим ноль, остаётся неопределённой.

## Веса и дополнительные срезы

Веса похожести получены регуляризованной LogisticRegression(C=0.1) для различения старых и текущих доступных ковариат; без ответов текущей выборки. Их ограничение0.2–5 задано заранее. Календарные веса — фиксированное циклическое расстояние по месяцу. Внутренняя дата всегда использует собственную популяцию, а не будущую внешнюю. Оба варианта проиграли; не рекомендуются для отправки.

D2 использует уже проверенные194949 исторических целей вместо50852. Все цели точно восстановлены из внутренних транзакций. Веса1/n(customer,month) вычисляются после purge. Календарь описывает долю каждого месяца в точном30-дневном горизонте, а не только месяц начала. D2 не дал уверенного преимущества и не рекомендуется как новый лучший.

Ранее подготовлен отдельный `submission_monthly_target_cohort_cpu.csv`:32774 прошлых строки клиентов текущей популяции, без прошлых ответов как дополнительных признаков. Его измеренный исход Kaggle: Private **2.70881**, Public **2.67892**. Вариант проиграл обоим текущим лучшим результатам; повторять его не требуется.

## Воспроизведение

На CPU, из корня репозитория с официальными CSV и существующим базовым cache:
```bash
python scripts/run_season_transfer.py --refit-only --profile transfer_market_mlp --cache outputs/behavior-cpu-screen/base_cache --out outputs/season-transfer-refit
```

Дополнительные срезы:
```bash
python scripts/prepare_monthly_snapshot_features.py --cache outputs/behavior-cpu-screen/base_cache --out outputs/monthly-snapshot-features
python scripts/run_augmented_monthly_mlp.py --features outputs/monthly-snapshot-features --refit-only --out outputs/augmented-monthly-refit
```

Обе команды финального рефита проверены с нуля: полученные CSV побайтно совпали с исходными. Полностью перестроенная матрица198137×83 также совпала, включая NaN.

12 целевых тестов прошли. Все финальные CSV проверены по3188 Id, порядку, схеме, finite/nonnegative/expm1; загруженные веса точно воспроизводят построчные log-прогнозы. В первом полном запуске отчёт остановился на слишком строгом сравнении round-trip float из CSV; допуск1e-12 исправил только отчёт. Функции обучения и сохранённые прогнозы не менялись; исходники фактических fit сохранены вместе с манифестами.
