## Прошлые официальные ответы и текущая популяция

Новые четыре исторических признака используют только официальные прошлые
метки с **target_end<=as_of_date конкретного объекта**: число доступных
ответов, сглаженный средний log-ответ, долю нулей и EWM. Они отличаются
от непрерывных 30-дневных интервалов назад: календарные окна имеют другую
фазу, а официальная выборка содержит только активных клиентов.

Это не статическое кодирование по всему train. Текущая и будущие метки
не используются. В частности, февральское окно, заканчивающееся3марта,
не доступно1марта. Тесты отравления собственного/будущего ответа и
граничной доступности прошли.

Второй эксперимент фильтрует исторические train-строки по известным ID
клиентов прогнозной выборки. Текущие ответы не читаются. Для inner даты
применяется её собственная прогнозная популяция, а не будущие ID outer
даты. Raw-проверка показала: все3188testклиентов в точности совпадают с
активными за180дней до2018-11-01, то есть состав популяции известен из
доступной истории, без будущих покупок.

## Проверка разрешённых ансамблей

Повторно прочитаны семинар9 и README курса на фиксированномSHA8a20cdf.
Полное дерево репозитория проверено через публичныйGitHubAPI:
дополнительных notebook семинара9нет. Семинар9 явно включает ансамбли
правил и RandomForest. Общее DummyEnsemble и задание на Bagging находятся
в семинаре11. Поэтому универсальное усреднение MLP не объявляется
подтверждённым методом до10; случайный лес используется как разрешённый
ансамбль деревьев.

Проверены3случайныхлеса по400деревьев с меньшими листьями и случайными
подмножествами строк. Локальные результаты2.639489/2.633812/2.631654;
весов/CSV/Id/чисел проверка прошла. Это альтернативы, локально не лидеры.
Конфиг `configs/course10_fast_forests.json`, скрипт `scripts/run_fast_forests.py`.

Все скоры в таблицах — локальная временная проверка, а не прогноз
Kaggle-score. Даты многократно использовались, исследование адаптивное.
Гиперпараметры вариантов заданы до их проверки; early stopping использует
более раннюю дату. Текущие/будущие ответы в fit не попадают. Никаких
ноябрьских коэффициентов по leaderboard и внешних транзакций нет.

Все готовые файлы собраны в `outputs/quick-variants-20261116/` с отдельными
