## Воспроизведение разбора

```bash
python scripts/analyze_hw4_masked_results.py \
  --incoming /path/to/four-returned-files \
  --raw data \
  --baseline /path/to/extensions_screen/predictions.csv \
  --out analysis/hw4-masked-results-audit
```

Baseline-файл — сохранённые OOF первоначального plus_context seed42, не
повторный fit. При изменении основных исходников можно указать--source-root
на сохранённую копию проверенных6 исходников.
