# Первые результаты

Полный запуск 9 ноября 2026 года на CPU (macOS arm64), seed=42, два потока. Фиксированные настройки из configs/baselines.json, базовые признаки RFM. Подбора параметров по этим результатам не выполнялось.

| Бейзлайн | Сентябрь RMSLE | Октябрь RMSLE |
|---|---:|---:|
| logmean | 2.667684 | 2.737917 |
| ridge | 2.660698 | 2.690830 |
| forest | 2.633360 | 2.697292 |
| mlp | 2.659560 | 2.758876 |

Лучший результат на сентябре — у леса, на октябре — у линейной модели. MLP в первой конфигурации не дал устойчивого улучшения. Это начальная точка для дальнейших ручных экспериментов, а не завершённое решение.

## Воспроизведение

```bash
python -m spend_baselines validate --models logmean ridge forest mlp --device cpu --threads 2 --out-dir outputs/validation-initial
```

- Сентябрь: 45 165 обучающих / 2 768 проверочных объектов.
- Октябрь: 47 933 обучающих / 2 919 проверочных объектов.
- Во всех случаях train ограничен target_end <= дате проверки.
- Все 50 852 train-ответа восстановлены из транзакций без расхождений.
- Линейная модель воспроизвела прежний исследовательский расчёт с точностью лучше 1e-9 RMSLE.
- Девять тестов очистки, времени, метрики, формата ответа и моделей прошли, включая повторный короткий MLP-запуск с одинаковым seed.
- Проверена локальная генерация submission_ridge.csv: 3 188 строк, правильные ID и порядок, конечные неотрицательные суммы. Файл в Git не включён; в Kaggle не отправлялся.
- CUDA/V100 в этом запуске не использовалась. Возможность CUDA предусмотрена кодом, но на GPU ещё не проверена.

Агрегированные метрики: [baseline-scores.csv](baseline-scores.csv). Версии, параметры и SHA256 файлов/исходников: [initial-run-manifest.json](initial-run-manifest.json). Времена в таблице зависят от загрузки CPU и не являются сравнительным бенчмарком.

Локальные RMSLE нельзя напрямую сравнивать с public leaderboard, который считается на другом наборе клиентов. При будущих экспериментах нужно сохранять этот запуск как исходный результат и учитывать повторное использование проверочных дат.
