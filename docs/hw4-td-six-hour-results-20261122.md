## Два рецепта, один алгоритм

В [исходном `CB_TD_CLASS` авторов Better by Default](https://github.com/dholzmueller/pytabkit/blob/main/pytabkit/models/sklearn/default_params.py#L87-L92) проверены параметры:1000-tree cap,lr.08,depth7,L2=1e−5,Plain,Bernoulli.9,random_strength.8,one_hot_max_size15,leaf_estimation_iterations1,border254. Второй рецепт меняет толькоL2 на1. Стек пакетов не обновлялся.

Адаптация кHW4 — та же причинная346-feature схема и старые временные кварталы. Исходный early stopping300 заменён заранее выбранной innerAP-сеткой100/250/500/1000. Это не точное воспроизведение опубликованного benchmark и не выбор лучшей из двух моделей по внешней оценке.

Для каждого outer2023Q3/Q4/2024Q1 оба рецепта сначала обучены только на данных до предыдущегоinner-квартала. Конфигурацию иN выбирал только соответствующийinnerAP. Все шесть внутренних paths завершились до первого outer-fit. На каждом из трёх внешних кварталов алгоритм выбрал **L2=1,N=100**; оригинальныйL2=1e−5 получил внутреннюю оценку, но не отдельный внешнийfit. Финальный рецепт по агрегированным трём старымINNER также был быL2=1,N=100,однако полныйfit не разрешён gate.
